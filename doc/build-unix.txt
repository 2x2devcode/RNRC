UNIX BUILD NOTES (Ubuntu 22.04 / 24.04 / 26.04)
================================================

These notes update the legacy build instructions for modern Ubuntu
toolchains (GCC 11–13+, OpenSSL 3.x, Boost 1.74+, Qt 5.15).

To Build (daemon / CLI)
-----------------------

    sudo apt-get update
    sudo apt-get install -y build-essential libssl-dev libboost-all-dev \
        libdb++-dev libminiupnpc-dev libqrencode-dev

    cd src/
    make -f makefile.unix -j$(nproc)    # produces RNRCd
    strip RNRCd

To Build (Qt GUI)
-----------------

    sudo apt-get install -y qtbase5-dev qtbase5-dev-tools qttools5-dev-tools \
        libqt5gui5 libqt5core5a libqt5dbus5 libqrencode-dev

    # From repository root:
    qmake "USE_UPNP=-" "USE_QRCODE=1"
    make -j$(nproc)                     # produces RNRC-qt

Notes for Ubuntu 22.04+
-----------------------

 * Package `qt5-default` was removed; install `qtbase5-dev` instead.
 * OpenSSL 3.x is used by default; the tree was updated for opaque BIGNUM /
   EVP_CIPHER_CTX / ECDSA_SIG APIs.
 * Boost.Filesystem `is_complete()` / `system_complete()` were replaced with
   `is_absolute()` / `absolute()`.
 * Build uses `-std=c++17` and links `libboost_chrono`.
 * Optional UPnP: `make -f makefile.unix USE_UPNP=1` (requires libminiupnpc-dev).
 * Optional QR codes (GUI): `qmake "USE_QRCODE=1"`.

Dependencies
------------

 Library     Purpose           Description
 -------     -------           -----------
 libssl      SSL Support       Secure communications (OpenSSL 1.1+/3.x)
 libdb       Berkeley DB       Blockchain & wallet storage
 libboost    Boost             C++ Library (system, filesystem, thread, chrono, ...)
 miniupnpc   UPnP Support      Optional firewall-jumping support
 libqrencode QRCode generation Optional QRCode generation (GUI)
 Qt5         GUI               Widgets / DBus for RNRC-qt

Versions typically provided by Ubuntu packages:

 Ubuntu 22.04  — GCC 11, OpenSSL 3.0, Boost ~1.74, Berkeley DB 5.3, Qt 5.15
 Ubuntu 24.04  — GCC 13, OpenSSL 3.0, Boost ~1.83, Berkeley DB 5.3, Qt 5.15
 Ubuntu 26.04  — same class of APIs; use the same package names above

miniupnpc may be used for UPnP port mapping. UPnP support is compiled in and
turned off by default when USE_UPNP=0. Set USE_UPNP to control this:

 USE_UPNP=-    No UPnP support - miniupnpc not required
 USE_UPNP=0    (makefile.unix default) UPnP support off by default at runtime
 USE_UPNP=1    UPnP support on by default at runtime

Security hardening flags (stack protector, RELRO, FORTIFY) remain enabled in
makefile.unix. See historical notes below for PIE testing with scanelf.
